## Closing a task (W6-12 — the round-2 lesson)

Five of round 2's twelve findings were gaps in fixes that closed their `Done when` boxes honestly:
the boxes described the reported INSTANCE, not the property (R2/R3/R4/R9/R12 — the table in
[done/W6-12](done/W6-12-fix-adjacency-review.md)). Three rules before ticking the last box:

1. **Enumerate the adjacent cases.** For a guard: the zero case *and* the one-unit case *and* the
   boundary its sibling already handles (GHSA-458x fixed `(0,0)`; `(0,1)` behaved identically).
   For a call site: grep the *mechanism*, not the reported line, and list every hit with a verdict
   — re-run the grep, never inherit it (W5-19 indexed six walks; R9 found five reader paths still
   scanning).
2. **Assert the specific series the fix claims to move**, never a proxy that aggregates it away.
   `test_volume_credit` asserted a role-agnostic badge, so the taker-role bug (W4-22) passed it;
   the fix was about *whose* volume it was. Worked example of the repair:
   `test_ghsa_round4.sh`'s W3-10 block asserts the exact refusal strings and the tape count.
3. **When a fix adds a helper on a hot path, cost it** — the same instruction-count note W5-19
   demands of the paths it bounded. W4-07 introduced a full-map scan per swept order in the same
   commit as an audit about uncapped scans (became W1-07, measured at 987k/order worst-case
   post-fix).
